# Archive

Old session notes and old status snapshots live here. Archiving keeps the pages that every
session reads short without losing history.

## Status snapshots

When the **Done** list in [Status](../status.md) grows past roughly 50 items, archive it:

1. Copy `docs/status.md` to `docs/archive/status-YYYY-MM-DD.md`.
2. Keep only the **Done** section in the copy.
3. Replace **Done** in `docs/status.md` with a link to the snapshot.
4. Add the snapshot to the table below.
5. Run `python -m mkdocs build --strict`.

| Snapshot | Date | Contents |

| — | — | — |

## Session notes

Session notes are never deleted. They are the chronological record of the project and are
linked from the [session index](../sessions/index.md). If the list becomes too long, split
the index by year (`sessions/2026.md`) and keep the newest year on the main page.
